# SQL Practice Repository

## About
This repository contains my SQL practice queries using PostgreSQL.
I am building my SQL fundamentals as part of my learning journey
towards becoming a Data Engineer.

I write and execute queries in DBeaver and maintain my practice
files using Visual Studio Code and GitHub.

## Topics Covered

- SQL Fundamentals: SELECT, WHERE, DISTINCT, ORDER BY, LIMIT and OFFSET
- Filtering: IN, BETWEEN, LIKE and NULL checks
- Aggregate Functions: COUNT, SUM and AVG
- GROUP BY and HAVING
- SQL Joins: INNER JOIN, LEFT JOIN and RIGHT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions: ROW_NUMBER and RANK

## Tools Used

- PostgreSQL
- DBeaver
- Visual Studio Code
- Git and GitHub

## Practice Approach

- Practising queries using sample customer, product and order tables created by me.
- Executing queries and checking results in DBeaver.
- Documenting queries with comments and related examples.
- Updating this repository as I learn new SQL concepts.

## Learning Goal

To strengthen my SQL skills and apply them to real-world
data processing and Data Engineering projects.

## Status

Learning and updating this repository.
